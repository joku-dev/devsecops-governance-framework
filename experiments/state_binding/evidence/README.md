# Vertrauliche Versuchsnachweise

Hier werden gezielt ausgewählte Pakete nach erfolgreicher Validierung
aufbewahrt. Die Pakete enthalten ausschließlich kontrollierte Testdaten.
Persönliche Demonstrationsdaten bleiben separat, bis eine echte Erklärung
erfasst und ausdrücklich als solche dokumentiert wurde.

Der nach Abschluss erzeugte Laufbericht benennt Quellcommit, Prüfsummen,
unabhängige Prüfung und vollständige Repository-Validierung. Die ZIP-Datei
kann direkt mit `../verify_evidence.py` geprüft werden, ohne manuell zu entpacken.
