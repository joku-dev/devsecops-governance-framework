The existing architecture report is unversioned. This adapter therefore names
its exact supported shape as `architecture-gate-report@legacy-shape-v1` and
requires all four known gates with internally consistent statuses and counters.
One gate produces one candidate even when it has multiple textual findings.
Marker-level outcomes, recommended work and exception authorities are not inferred.

The decision brief makes the next live step concrete: pilot scope, named role
slots, consent-channel proposal, producer/trust checks, freshness/replay choices
and accountable acceptance. It leaves those decisions open. Portfolio expansion
requires admitted live consumers; optional AI is not a prerequisite for that step.
