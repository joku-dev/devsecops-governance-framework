operating values. This change prepares the first actual personal-channel test

The request is bound to the confirmed operating profile, role binding and durable
receipt head. A personal comment on PR #87 must reference the exact request digest,
state its disposition and explicitly attest that the appointed person issues it
personally. This agent prepares the text but must not post that assertion for the
person. No self-approval of a PR is needed: the channel test is an ordinary comment
on the already existing PR discussion and is not a PR review or merge consent.

GitHub authenticates the account, not physical human presence or use of its web
UI. The verifier therefore reports explicit personal self-attestation separately
from provider identity. Known bots/apps, edited statements, mismatched targets and
invalid withdrawal history cannot confirm the probe. Even a confirmed probe grants
no remediation, closure, role change or live activation; LD-07 remains separate.
