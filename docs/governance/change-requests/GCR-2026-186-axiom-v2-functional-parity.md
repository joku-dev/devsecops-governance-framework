## Intent and classification

On 15 November 2026 the maintainer requested autonomous implementation of full
technical V1/V2 functional parity, using `joku-dev/ha-CPsWMS` as a real comparison
target. The root `AXIOM_V2_Functional_Parity_Codex_Goal.md` records the objective.
This is a technical product completion/change, not a normative governance source.
V1 reference is immutable `6b557fefe295b58272d2271326576ca3a3687197`; V2 starts
at `b6e3b64951456b5878a98810d50ba17cbe89dfe0` from PR #395.

## Required behavior

All 22 catalogue areas and V1 execution/operating entrypoints require explicit,
installed, provider-neutral V2 counterparts. Source-file retention, raw legacy
CLI wrappers and historical read-only data are not parity evidence. No feature
may be removed from this scope without a named maintainer decision.

Scope includes document/requirement lifecycle, DCR, full existing DevSecOps and
architecture evaluations, measured L1 assessments, accepted-result intake,
reporting/graph/Viewer/release tools, agent review functions, findings/actions
and repeatable service/update/backup/recovery operation. New V2 technical
ability does not inherit old personal consent, roles, waiver authority or
operating acceptance. Preserve released baselines, policies, historical records
and the protected V1 pilot implementation fingerprint.

## Evidence and delivery

Pin the real consumer commit/evidence/run/attempt/baseline/time/context before
comparing V1 with V2. Compare coverage, statuses, findings, Trust, evidence binding
and projections; explicitly distinguish replay, synthetic fixtures and a fresh
native producer run. Do not suppress differences or invent missing evidence.

Maintain a source-bound parity matrix with pending/in-progress/verified states
and actual positive, negative and installed end-to-end evidence. Deliver coherent
validated commits/PRs and isolated Mac/Linux installation candidates. Unknown
external target editions/access or new human approval requirements remain
specific acceptance limits, not reasons to stop independent implementation.
