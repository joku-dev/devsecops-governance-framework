# Geltungsbereich und Grenzen

Die Pilotpublikation ist erklärend. Ihre Anforderungen steuern den Aufbau und
die Veröffentlichung dieses Dokuments. Sie ersetzen keine freigegebenen
Governance-Quellen, Controls, Architekturmarker oder Baselines.

Die Felder `source_ids` und `control_ids` bleiben leer, solange keine
freigegebene fachliche Herkunft besteht. Dadurch wird keine künstliche
Traceability erzeugt. Eine spätere Zuordnung muss den regulären
Governance-Änderungsprozess durchlaufen.

Ein organisationsspezifisches Word-Layout benötigt ein freigegebenes
Referenzdokument mit Logo, Schriften, Farben, Kopf- und Fußzeilen. Bis diese
Vorgaben vorliegen, verwendet die Pipeline ein neutrales reproduzierbares
Layout.
