# Zweck und Zielbild

Dieses Dokument beschreibt den Doc-as-Code-Pilot für professionelle
Publikationen aus Git. Markdown-Dateien bleiben die bearbeitbaren Quellen. Eine
versionierte Manifestdatei ordnet die Inhalte, und eine gepinnte Werkzeugkette
erzeugt HTML, Word und PDF.

Anforderungen liegen jeweils in einer eigenen Markdown-Datei. Damit lassen sie
sich gezielt ändern, prüfen und erweitern, ohne ein großes Gesamtdokument
bearbeiten zu müssen.
