Änderungen an Manifest, Kapiteln, Anforderungen, Schemas oder Renderer müssen
vor der Veröffentlichung gemeinsam als Pull Request geprüft werden. Die
Vorschau muss denselben Publikationspfad wie die spätere Veröffentlichung
verwenden.
