Der inhaltliche Ausgangspunkt einer Publikation muss aus versionierten,
menschenlesbaren Dateien im Repository bestehen. Binäre Exporte sind erzeugte
Ergebnisse und werden nicht als parallele redaktionelle Quelle gepflegt.
