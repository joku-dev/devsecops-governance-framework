# Persönlicher GitHub-Kanaltest

Diskussion: https://github.com/joku-dev/devsecops-governance-framework/pull/87

Bitte als `joku-dev` selbst einen neuen Kommentar mit dem folgenden vollständigen Inhalt posten. Die Erklärung prüft ausschließlich den persönlichen Freigabekanal. Sie gibt keine Behebung, keinen Abschluss und keine Live-Aktivierung frei.

```text
CLG-PERSONAL-CONSENT/1
{
  "disposition": "approve",
  "request_digest": "ad1ab390a6a0a85d6af9dcd12b6fca7dc2276ccf474b977e196977b94b318f07",
  "statement": "Ich habe diese Anfrage persönlich geprüft und gebe diese Erklärung selbst ab; keine Automation handelt dabei für mich.",
  "supersedes_comment_id": null
}
```

Nicht durch Codex oder eine andere Automation posten lassen. Einen abgegebenen Kommentar nicht bearbeiten oder löschen; Ablehnung und Widerruf werden als neue, referenzierende Kommentare erfasst.
