# Persönliche Betriebsabnahme LD-07

Bitte zuerst den vollständigen Antrag und den Betriebsleitfaden prüfen. Diese Erklärung gibt den beschriebenen manuellen GRS-002-Piloten im Report-only-Modus frei. Behebung und Abschluss benötigen weiterhin eigene persönliche Erklärungen.

Diskussion: https://github.com/joku-dev/devsecops-governance-framework/pull/91

```text
CLG-PERSONAL-CONSENT/1
{
  "disposition": "approve",
  "request_digest": "0ac280399f7ef5fb1af490dd0f9ca02be356ddac38cba2ae192c6ec82185114a",
  "statement": "Ich habe diese Anfrage persönlich geprüft und gebe diese Erklärung selbst ab; keine Automation handelt dabei für mich.",
  "supersedes_comment_id": null
}
```

Die benannte Person gibt den Kommentar selbst ab. Codex darf ihn vorbereiten, aber nicht stellvertretend posten.
